# 0.1.5：Iris 命名迁移与恢复

[English](en/namespace-migration.md)

0.1.5/e25 将产品自身的包名、设备目录、原生助手、音频服务、套接字和资源组统一为 Iris 命名。宿主 App 为 `com.irisbox.viewer`，运行根为 `/data/irisbox`。实例编号、数据 revision、User namespace UID/GID 范围、ROM 绑定和游戏数据保持。共享 INET 分派器经核验后复用；它的既有路径及其他项目表不迁移或删除。

**已有 0.1.4/e21 安装不能仅覆盖 APK。** 包名变化使它成为新应用，需要正常重新授予宿主 Magisk root。不要手工复制 root 授权数据库，不要清空 Google 服务或重新生成实例。全新安装仍按普通安装指南操作。

## 维护者迁移步骤

此工具仅支持已核验的 0.1.4/e21 → 0.1.5/e25。先保留实际安装的旧 APK、签名密钥及足够的独立备份空间。旧工程只作只读参考，不能把旧工程目录当迁移源。

1. 从 App 正常停止本产品全部实例，等待显示、网络、挂载及后台任务清理完成。关闭旧入口，避免重新连接。
2. 设置自己的 ADB 设备；公开源码使用 `IRISBOX_SERIAL`。工具从旧 APK 读取原包名和设备根，核验已安装 APK 与引擎逐文件摘要、PID:start_tick、空资源组、网络账本及镜像挂载归属。不满足即停止。
3. 先只检查，再执行：

   ```powershell
   python tools/migrate_namespace.py --from-apk out/IrisBox-0.1.4.apk --to-apk out/IrisBox-0.1.5.apk
   python tools/migrate_namespace.py --from-apk out/IrisBox-0.1.4.apk --to-apk out/IrisBox-0.1.5.apk --apply
   ```

4. 工具在停机状态为每个实例复制独立的 data、upper、vendor.upper 和元数据，核对源/副本逐文件 SHA-256，保留配置与引擎回退材料。不是硬链接备份。随后释放经核验归属的只读底层挂载、停用旧入口、替换可信引擎并移动整套产品目录。停止状态的旧显示指针和旧音频文件保留在事务备份中，不继续使用其中的旧绝对路径。
5. 安装新 APK，打开“授权与检查”，在宿主 Magisk 正常允许新包，检查通过后启动实例。原包的授权不自动继承。迁移工具本身不自动卸载旧 APK；完成数据、账号、显示、输入、网络及隔离验收后，维护者才可备份并移除旧入口。

私有收据在 `out/maintenance/namespace-transition.json`；记录实际事务目录、完整数据快照及状态。不得公开收据、账号指纹、原始日志或设备截图。迁移后的备份跟随产品根位于 `/data/irisbox/maintenance/` 或收据指定的事务目录，**同盘备份不能代替外部备份**。

自带下载浏览器的包名也有变化。旧包专属缓存/DownloadManager记录不会自动转成新UID的下载历史；原下载文件及旧状态留在完整快照中。Google、游戏等第三方应用包名保持，其账号与数据按原UID布局保留。

## 故障与回退

`engine-upgrade.pending` 存在时不得强行启动实例。先保留收据和错误输出，确认所有实例及显示进程停止，检查收据指向的 `recover.sh`。不要猜测目录后删除标记、批量改属主或重新运行所有初始化脚本。

提交过程失败时，事务会尝试用原引擎及原路径回退。本次实测发现过源脚本的短变量覆盖事务目标变量；修正为专用变量并隔离检查后重新迁移成功。首次失败的自动回退保留了数据，随后严格核验通过。

生成的恢复脚本用于该次**停机目录/引擎事务**，不是任意时间点的数据恢复器。若维护者已卸载旧入口，需先重新安装**同一份旧 APK**，才能恢复它的入口和正常授权；完整快照恢复还涉及对应 revision、UID 映射、挂载和配置核验。不要在新实例继续写入后直接覆盖旧备份，也不要把旧引擎套在不匹配的所有权布局上。需要恢复 Google 使用时，先按 [Google 恢复指南](10_Google商店恢复与认证说明.md) 检查网络、时间、账号及实际商店，避免清空 GSF。

## 已验证范围

本轮实际迁移两个已有实例，保留 ID、revision、UID/GID 映射；实例2的 Google 账号私有指纹与 GSF ID 保持，重启后能继续从 Play 安装应用。新 App 正常获得宿主授权，中英文设置及真实全屏游戏输入通过。旧独立项目只按授权正常停止，数据与配置保留。具体游戏、双开及限制见 [验收记录](06_验收记录.md)。宿主 Magisk 仍由使用者自行安装；Google 设备认证仍未通过。

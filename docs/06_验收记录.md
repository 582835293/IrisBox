# 2026-10-15 实机验收记录

本记录区分本项目新建环境的实际结果与旧项目历史能力。设备为树莓派4 / 固定AOSP13 / 约4GiB内存。旧Iris实例7在本轮开始时运行，其余旧实例8、23没有活跃init。测试起初保留旧实例运行；随后用户明确回复“直接关闭之前的吧，也不用恢复了。暂时用不到了”，据此正常停止旧实例7及旧后台，保留数据与配置，不再恢复旧项目。没有复制旧账号或旧实例data。

## 已完成的安装与静态检查

- 独立APK包名、签名、API33目标版本；安装没有覆盖旧Iris。继承的API30目标版本曾被系统拦截，已调整为API33，通过正常安装完成，未关闭安装保护。
- App经宿主Magisk正常授权，拒绝时可见失败提示；随后通过Magisk仅开启RootVMOS开关。旧Iris授权保持。
- App内宿主检查、内置引擎首次安装、系统文件选择器返回文档URI、解压/摘要校验、root ROM库提交均已实际完成。
- 生产PackageArchive在Android上执行11项测试全部通过：正常包、坏SHA、缺文件、重复项、未声明项、超出声明大小、错误profile、路径穿越、绝对路径、错误首项和超大清单。
- 本地与设备引擎39项摘要、Shell语法、116项ROM适配profile、54项Google静态文件、11项Magisk组件通过核验；e2原生助手已实际执行new-cgroup并正常退出。
- 旧本地52项当前源码输入与提取时摘要一致；关闭旧项目以前，设备旧脚本/注册表/内存/分辨率配置、活跃init PID:start_tick、Host boot_id和根socket策略在多次对照中保持一致。授权关闭以后，旧文件和身份记录继续保持，正常停止回收旧实例网络。宿主重启会重建内核对象，不以BPF数字ID不变作为重启后要求。

## 遇到并保留的失败

1. Google原始清单含特定换行字节，初次提取格式化改变了摘要。组件审计在导入前发现，恢复原始字节并重新打包；Git attributes为固定组件禁用自动文本转换，54项审计通过。
2. e1首次新实例启动在创建Guest前返回3：脚本调用rootvmos_ns，包内文件仍叫iris_runtime_ns。统一二进制打包/安装名称为rootvmos_ns，新增文件名与ARM64检查，升级为e2。e1本轮测试安装在停止本项目后台、确认无Guest/init/网络/挂载后归档至`/data/rootvmos/qa-e1-20261015`；ROM与测试设置保留。旧Iris没有迁移或覆盖。
3. e2重新从APK安装并再次走系统文件选择器导入，同一ROM包继续校验并成功启动。
4. 512MiB的新实例冷启动触及内存限制，未进入桌面。正常停止该新实例，调至768MiB后成功；因此不能将可配置下限512MiB宣称为推荐可用内存。
5. 文件交换测试连续提交操作时曾收到423：上次HTTP下载刚结束，但后台仍在释放操作锁。测试改为有限次数等待后重试，最终逐字节及摘要对照通过；没有绕过锁。

### 真实宿主重启

停止全部新Guest并同步后正常重启树莓派。Host boot_id由`13a37c82-d769-436b-8c55-3751ea0691ab`变为`11e48d19-552f-4a85-bafc-5db16aa6d3a7`，宿主版本和Permissive保持。没有打开旧Iris，也没有从电脑重新部署引擎或ROM。直接打开新App进入管理页，后台自行恢复并保留两实例配置；App按钮启动1007，42,083ms进入桌面，启动1008，46,919ms进入桌面。初次测试等待上限45秒不足以覆盖后者，延长观察后就绪；产品没有报错。开发等待工具上限已调整为90秒。

两实例重启后的Probe仍为普通UID10084，计数分别保留1和2，HTTPS均返回200，列表两张预览持续更新。新联网助手`verify`通过分派器、原宿主程序和宿主map匹配校验。`compare --old-stopped --host-rebooted`通过：Host确已重启、旧Guest无活跃init、旧脚本/配置/注册表和身份记录不变。

## 2026-10-21：0.1.3 / e17 User namespace实机回归

本节为当前新增结果，上文保留各版本当时的验收。参考旧项目2026-10-20已接入的User namespace实现，移植到独立产品范围，并处理私有0700设备目录、私有BusyBox和本项目音频桥差异。旧工程只读；本轮发现旧Guest再次运行，经用户明确授权正常停止，保留配置及数据、不恢复。

- 双开真实全屏、两个显示FD交接、键盘输入`Iris42Z`、滑动、实际“返回列表”按钮及再次进入通过；主Guest会话和原计数保持。
- 普通UID HTTPS200、Google连通性204、DNS、V3D GLES与像素检查通过；无INTERNET权限应用的HTTPS/Google端点/DNS均被拒绝。
- 两实例PCM非零、640×360/24fps H.264编码及播放渲染和播放进度通过。实例2普通App通过已保留的Magisk授权取得Guest uid0。
- 两实例分别完成同名不同内容51字节文件导入/导出及摘要对照；每实例10张640×360 JPEG预览通过。
- 缺失/错误Bearer均403。定向终止音频采集助手后21.44秒恢复，替换Host播放器和采集进程，主Guest会话不变。
- 退出重开APK及停止/恢复本项目管理后台均保持Guest会话、数据和音频。回归时Guest crash buffer无新崩溃，cgroup OOM-kill计数均0。
- 实际英文/简体中文管理页切换通过，335项资源键与Java引用一致；实例语言、会话未变，最后保留原简体中文选择。
- Android生产解包器11/11安全用例通过；Google私有输入54、Magisk11、ROM兼容116、引擎49项摘要通过。公开快照独立完整构建的49项引擎载荷逐项相同。
- 旧项目本轮基线对照通过：旧脚本、配置、注册表、身份记录、Host boot与根socket策略不变，旧Guest均停止；全局Host BusyBox摘要不变。旧项目源码参考输入摘要另有记录。

### 失败、修复与没有放宽的边界

开发候选e14在执行Guest前因Root暂存变量顺序错误拒绝，e15修正；e15的0700产品路径不能供映射身份穿越，e16采用仅私有挂载空间内的`/mnt`入口，Host目录仍0700；e16的GNU BRE可选表达式在APK BusyBox不适用，e17改为两个明确匹配，移除Guest不接管的蓝牙声明。闹钟权限、委派vmpressure、RTPRIO、显示/声音映射凭据一并按旧实现和本项目边界适配。

开发测试一次在768MiB实例全屏时额外启动UiAutomator ART进程，造成重度回收，现有内存保护正常停止Google实例；未发生OOM kill。测试改为进入全屏前读控件位置，按原配置重新启动并再次核对账号、revision和计数。没有提高内存上限或关闭保护。超长瞬时ADB按键序列触发现有32事件有界队列的取消语义，改用短混合大小写输入验收；没有扩大队列。一次H.264编码受启动负载影响超过20秒测试预算，保留失败记录，原参数单项重试与完整双实例复测均通过。

### Google商店与未验证项

本轮实际打开商店显示“This device isn’t Play Protect certified”，**商店目录/下载未通过**。迁移前后GSF ID一致，SSAID文件逐字节一致，Google账号私有HMAC保持；迁移前备份也存在未认证缓存。不能据此确定本次提示的触发原因，也不能以账号条数代替商店验收。没有清空GSF/GMS/商店数据、修改认证判断或伪造设备指纹。

用户随后确认已使用当前实例自己的GSF ID完成[Google自定义ROM官方登记](https://www.google.com/android/uncertified/)，并明确授权正常check-in同步复测。日志有check-in成功，但实际商店仍为未认证页、目录未加载。用户要求暂不继续排查，保留数据收尾；没有据此认定为服务器审核或承诺等待即可恢复。登记不等于厂商认证、Play Integrity或所有游戏可用。

本轮没有重启宿主、重刷物理介质或重新编译整个AOSP。先前版本的Host重启记录不能替代映射版本重启验收。冷刷首启、完全干净宿主的共享分派器首次安装、Enforcing、其他ROM/内核、Android多用户、任意Root模块、DRM和长期恶意负载隔离未验证。共享内核/GPU及Permissive限制仍在。中英文README新增的是使用流程示意图，未公开设备原始截图、账号或日志。

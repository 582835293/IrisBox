## 1. 宿主支持范围与前置要求

- **目标硬件**：Raspberry Pi 4（ARM64，约 4 GiB 物理内存）。
- **唯一匹配宿主构建指纹**：
  ```text
  Raspberry/aosp_rpi4/rpi4:13/TQ3A.230901.001/eng.lijiaq.20260916.141216:userdebug/test-keys
  ```
- **内核与环境要求**：
  - 宿主需具备可用的 **MagiskSU**、已配置为 **Permissive** 的 SELinux 环境，以及已联网的 `wlan0`。
  - 内核必须支持 `User` / `Mount` / `PID` / `Network` / `IPC` / `UTS` / `Cgroup` 七类命名空间、`OverlayFS`、`binderfs`、混合 cgroup 控制器、BPF socket 权限策略及匹配的 Mesa/V3D GPU 驱动。
  - 自 `0.1.3` 起**强制要求创建独立 User Namespace**，不存在 Host UID 0 回退路径。仅获得 Root 授权无法弥补内核特性或驱动缺失。
- **内置工具与存储余量**：
  - App 会自动检测上述宿主能力，并将经过 SHA-256 校验的 BusyBox 安装至项目私有目录 `/data/irisbox/host/bin/busybox`，无需修改宿主 `/system` 分区。
  - 导入 ROM 时会先在 App 私有目录解压校验，再提交至 root ROM 库。带 Google 的 ROM 解压后约占 2.5 GiB，建议宿主至少预留 **8 GiB 可用磁盘空间**（所选源压缩包体积另计）。安装与导入进度通过前台服务通知展示，切勿在复制期间强制停止 App 或断电。

> [!WARNING]
> **存量版本升级必读**
> - 从 **`0.1.4 / e21`** 升级至 `0.1.5+` 前，请先阅读 [0.1.5 Iris 命名迁移与恢复](11_Iris命名迁移.md)。
> - 从 **`0.1.2 / e13`** 升级至 `0.1.3+` 前，请先阅读 [停机备份与 User Namespace 迁移](09_User_namespace隔离与迁移.md)。仅覆盖安装新 APK 无法自动迁移旧属主元数据（在实测宿主上，768 MiB 普通实例首次映射启动约需 175 秒，1536 MiB Google 实例约需 78 秒，请耐心等待桌面就绪）。

## 2. 首次运行流程

1. **安装应用**：在树莓派宿主上安装 `IrisBox-0.1.6.apk`。该包拥有独立签名与包名（`com.irisbox.viewer`），不会覆盖旧参考工程。
2. **授予宿主 Root 与通知权限**：打开虹膜空间，在弹出的宿主 Magisk 窗口中点击允许（若误点拒绝，可在宿主 Magisk 应用内重新开启授权后再点击“授权与检查”）；允许通知权限以便查看后台安装/导入进度。
3. **宿主检查与引擎安装**：依次点击 **“1 · 授权与检查”**（确认宿主各项能力核验通过）→ **“2 · 安装内置引擎”**（引擎来自 APK 内置的签名校验包，不从旧项目目录读取）。
4. **导入 ROM 包**：点击 **“3 · 导入 ROM”**，通过系统文件选择器选择 `IrisBox-rpi4-a13-aosp.irisrom`（可位于宿主下载目录或 U 盘等文档提供者）并确认导入。
5. **创建实例**：点击 **“4 · 管理实例”** → 右上角 **“新增实例”**。可按需勾选可选的 Google Play 组件或实例应用 Root（Magisk）——注意**宿主 Magisk 授权**与**实例内应用 Root 开关**相互独立。
6. **启动与进入**：点击卡片上的 **“启动”**，等待启动日志显示桌面就绪后点击 **“进入”**。列表页提供约 1 秒/帧的低频预览，全屏交互则运行于独立的图形缓冲区管线。
7. **多开管理**：如需双开，点击“新增实例”创建第二个实例。每个实例拥有完全独立的应用、账号、文件与配置，但同时运行的数量受限于 4 GiB 树莓派的实际可用物理内存。

## 3. 内存上限、启动顺序与宿主交换空间

### 实例内存上限与准入保护
- **默认值与可调范围**：新建普通实例默认上限为 **1.25 GiB（1280 MiB）**，带 Google 的新实例默认为 **1.5 GiB（1536 MiB）**；实例停止状态下可在 **`0.5`–`2.5 GiB`** 范围内调整。
- **启动前物理内存准入检查**：每次启动实例前，系统会按配置的内存预算加上宿主安全余量检查物理 `MemAvailable`；若余量不足则直接拒绝本次启动，**绝不抢停已在运行的实例**。
- **实测配置建议**：
  - `0.5 GiB（512 MiB）` 仅为配置语法下限，实测空白实例在此预算下冷启动会因触及上限而失败。
  - 无 Google 实例已在 `768 MiB`、`1024 MiB` 下实测通过；带 Google 与 Magisk 的实例在登录并运行 Chrome 时若设为 `1280 MiB` 易频繁触发内存回收，调至 `1536 MiB` 或 `2048 MiB` 后稳定（新默认值即基于此设定）。
  - **双开启动顺序建议**：在 4 GiB 宿主上双开时，建议**先启动内存上限较大的 Google 实例（如实例 2），待就绪后再启动普通实例（如实例 1）**；反之若普通实例先占用内存，剩余 `MemAvailable` 可能不足以通过大内存 Google 实例的启动准入检查。

### 宿主交换空间（v0.1.6+）
- 在首页或实例列表顶部点击 **“交换空间”**，可配置宿主共享 Swap（**关闭 / 1 GiB / 2 GiB / 4 GiB**）并支持勾选 **“重启后自动恢复（宿主 Magisk）”**。
- 更改交换空间大小或关闭前，必须先**正常停止所有虹膜空间实例**。详细说明与游戏触屏操作指引请参阅 [交换空间设置、低内存与游戏触屏](12_低内存与临时交换空间.md)。

## 4. Google 账号登记与设备认证边界

- **独立 GSF ID 登记**：每个实例拥有独立的 GSF ID；此前在宿主或旧项目实例中做过的登记不会自动生效于新实例。若打开商店出现未认证提示，请按 [Google 自定义 ROM 官方登记页](https://www.google.com/android/uncertified/) 使用**当前实例自己的 GSF ID** 由本人登录完成登记。请勿公开 GSF ID，也不要反复清空 GSF 数据刷号。
- **登记 ≠ 设备认证**：保留 Google 登录或完成自定义 ROM 登记**不等于通过厂商设备认证（Play Protect Certification）或 Play Integrity**。当前版本已恢复商店目录与实际应用下载，但设置页仍显示 `Device is not certified`，详见 [实机验收记录](06_验收记录.md) 与 [Google 商店恢复与认证说明](10_Google商店恢复与认证说明.md)。

## 5. 日常操作与故障排查

| 功能项 | 操作规则与注意事项 |
| :--- | :--- |
| **后台驻留与重启恢复** | 退出宿主 App 不会停止运行中的实例；重新打开 App 进入管理页即可自动重连后台。宿主物理重启后，打开 App 手动点击“启动”即可，系统不配置宿主 `init` 开机自启实例。 |
| **实时横竖屏切换（v0.1.4+）** | 进入实例全屏后，点击顶部工具栏 **“横竖屏”** 可实时切换 **跟随应用 / 横屏 / 竖屏**（无需重启实例，且设置按实例持久化保存）。宿主窗口保持横屏，竖屏画面居中呈现；部分固定比例应用自身可能留有黑边。 |
| **配置修改、日志与文件交换** | 分辨率、内存上限、应用 Root 开关须在实例**停止后**修改并保存。启动日志按次保存，停止状态下可点击 **“上次日志”** 查看历史。文件导入/导出通过 Android SAF 读写实例专属的 `Download/IrisExchange` 目录。 |
| **多 ROM 导入规则** | 导入新 ROM 仅改变**后续新建实例**的默认 ROM，已有实例继续绑定创建时的 ROM ID。相同 ID 且清单摘要完全一致时允许幂等重导；相同 ID 但内容不同则拒绝覆盖（当前暂无 ROM 删除或跨 ROM 迁移界面）。 |
| **重置数据与删除实例** | “重置数据”清空选定实例的用户数据并保留配置；“删除实例”彻底移除该实例卡片与数据。两者均需输入实例编号二次确认。**切勿用重置或删除实例来排查宿主 Root 授权或 ROM 文件损坏问题。** |
| **导入或启动失败处理** | 归档损坏、路径越界、SHA-256 不匹配或缺失适配材料会在导入阶段直接拒绝，不会污染 ROM 库（App 正常退出时自动清理暂存文件；异常断电后的清理见 [构建与维护](04_构建与维护.md)）。新实例启动失败时请先保存启动日志排查。 |
| **公开发行说明** | 公开 ROM 包不含 Google 应用；现有私人 Google 实例升级时完整保留原 ROM、数据与登录状态。语言切换、干净宿主镜像刷入与验证边界详见 [国际化与发布](08_国际化与发布.md)。 |

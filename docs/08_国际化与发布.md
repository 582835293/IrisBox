# 虹膜空间 / IrisBox：国际化与发行

## 名称与语言

中文名称为虹膜空间，英文名称为 IrisBox。Android 默认资源为英文，`values-zh` 提供中文；App 内可选择跟随系统、English、简体中文。翻译源在 `app/viewer/i18n/translations.json`，`tools/generate_i18n.py` 生成资源和固定状态字典。用户文件名、ROM 名称、实例内部语言及原始技术日志保持原内容。

旧内部包名、数据根和协议继续保留，避免覆盖安装时创建第二份 App 或丢失入口。产品改名不会移动实例、重新登录 Google，也不会覆盖旧 Iris 包名。

## 干净宿主镜像的制作

来源为已有 AOSP 编译机的 Raspberry Vanilla 原始出厂镜像，不是当前树莓派 SSD 的整盘备份。`tools/clean_host_image.py` 只读原始 MBR、boot、system、vendor，逐分区与对应构建文件校验；**不复制源 userdata**，创建全新 ext4 userdata，仅含 lost+found，再合成为新文件。

原始大小 7,516,192,768 字节，XZ 后 537,835,072 字节。新 userdata 通过 e2fsck，合成后各分区摘要再核验。boot 保留原始 ramdisk，不集成宿主 Magisk、App、账号、实例 data、Wi-Fi 配置、ADB 授权或私人密钥。构建指纹中的用户名是原始 Android 兼容标识，不是账号凭据。

**目前完成文件级静态校验，尚未验证备用卡首次启动、扩容、新的 Magisk 安装及空白 INET 分派器安装。** 当前 SSD 和旧项目没有用于刷机验证。

## 刷入与首次配置

1. 校验 SHA-256，解压 `.xz`；备用介质建议 16GB 或更大，为 ROM 和实例留空间。
2. 用 Raspberry Pi Imager 的自定义镜像或整盘镜像工具，核对所选备用卡/盘的容量与身份。刷入会覆盖所选介质，不要选择含旧工程和实例的现用盘。
3. 首次启动后连接 Wi-Fi，核对指纹和内核。镜像是 userdebug，首版已配置 Permissive，不应视作安全隔离边界。
4. 使用者按板卡的 ramdisk 布局与 [Magisk 官方说明](https://topjohnwu.github.io/Magisk/install.html)自行安装宿主 Magisk。该板卡 `boot.img` 是 FAT 分区，含 `Image` 和 `ramdisk.img`，不能照搬手机 boot 分区刷写命令。此镜像尚未验证新的 Magisk 安装流程；已有宿主的正常授权已实测。
5. 安装 APK，运行“授权与检查”，通过后安装引擎、导入 ROM、创建并启动实例。宿主兼容错误不能靠重置已有实例解决。

## 设备树与源码

上游为 [Raspberry Vanilla Android13 manifest](https://github.com/raspberry-vanilla/android_local_manifest/tree/android-13.0)，AOSP 基线 android-13.0.0_r75。设备树、内核预编译仓库和 vendor 提交见 `reference/host-profile.json`。当前编译机设备树含后续实验改动，不能当成出厂镜像的完整源码快照。

镜像使用原始编译分区，不混入当前输出目录中可能为 Guest 重编的单个 init。容器补丁在 ROM compat 和新引擎内。完整从零重编并得到相同镜像字节尚未验证。

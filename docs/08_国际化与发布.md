## 1. 产品命名与多语言机制

- **双语品牌**：中文名称为 **虹膜空间**，英文名称为 **IrisBox**。
- **国际化资源架构**：Android 默认资源（`res/values/strings.xml`）为英文，`res/values-zh/strings.xml` 提供简体中文；宿主 App 顶部提供 **“EN / 中文”** 按钮，支持在 **跟随系统 / English / 简体中文** 之间切换并持久化保存。
- **翻译生成与边界**：所有 UI 词条统一维护在 `app/viewer/i18n/translations.json` 中，由 `tools/generate_i18n.py` 自动生成 Android 资源文件与运行期状态映射字典。宿主 App 语言切换**仅改变宿主管理界面文字**，绝不修改用户文件名、ROM 名称、各实例内部的 Android 系统语言或底层原始技术日志。

## 3. 干净宿主镜像（`.img.xz`）的合成原理与静态校验

- **只读分区提取 + 全新空白 `userdata`**：
  干净宿主镜像源自匹配 AOSP 编译机的 Raspberry Vanilla 原始出厂构建，**绝非从当前在用树莓派 SSD 导出的整盘备份**。`tools/clean_host_image.py` 以只读方式读取原始 `MBR`、`boot`、`system` 与 `vendor` 分区并逐一校验构建哈希，**完全不复制源 `userdata`**，而是重新格式化创建一个仅含 `lost+found` 的全新 `ext4` `userdata` 分区后合成为整盘镜像。
- **12 GiB `userdata` 扩容设计**：
  原始出厂镜像的 `userdata` 仅约 `4.6 GiB`，不足以同时容纳 `.irisrom` 压缩包、解压暂存区与导入后的 ROM 库。因此发行版干净镜像在保持原始文件系统特性标志不变的前提下，将全新空白 `userdata` 扩大为 **12 GiB**（解压后整盘原始字节数固定为 **`15,436,087,296 字节`**，约 15.4 GiB），并通过 `e2fsck` 与全分区摘要复核。
- **纯净性保证**：镜像的 `boot` 分区保持原始出厂 `ramdisk`，**未集成宿主 Magisk、未预装本 App、不含任何个人账号、实例数据、Wi-Fi 密码、ADB 授权密钥或私人签名密钥**（构建指纹中的用户名字段仅为原始 AOSP 构建兼容标识，非个人凭据）。

> [!WARNING]
> **干净宿主镜像的验证边界**
> 该整盘镜像目前已完成全部分区与文件系统的**静态校验**，但**尚未在备用物理 USB 盘上执行实际刷入、首次启动、新装宿主 Magisk 及首次创建全局 INET 分派器的实机测试**。现有已配置宿主上的实测不能替代空白 USB 盘的首次刷机验收。

## 4. 刷入备用 USB 启动盘与首次配置步骤

1. **确认 USB 启动模式（仅支持 `USB / sda`）**：
   原始出厂 `fstab.rpi4`（保存在 `reference/host-boot/fstab.rpi4`）硬编码挂载 `/dev/block/sda2`、`sda3` 与 `sda4`。因此该镜像**仅适用于 USB 启动盘（且首次启动时仅连接该目标 USB 盘以确保枚举为 `sda`），不能当作 SD 卡（`mmcblk0`）镜像使用**。树莓派 4 需预先配置好 USB Mass Storage 启动（参见 [Raspberry Pi 官方 USB 启动文档](https://www.raspberrypi.com/documentation/computers/raspberry-pi.html#usb-mass-storage-boot)）。
2. **校验并刷写镜像**：
   核对 `.img.xz` 的 SHA-256 摘要并解压，准备一块 **16 GB 及以上（可用字节数 ≥ `15,436,087,296`）的备用 USB 盘**。使用 Raspberry Pi Imager（选择自定义镜像）或整盘写盘工具写入（**刷写前务必确认盘符，切勿覆盖存有现有工程或重要数据的日常用盘**）。
3. **首次进入宿主系统**：
   连接显示器与键鼠启动树莓派，配置 Wi-Fi 网络，并在设置中核对系统构建指纹与内核版本（该镜像为 `userdebug` 构建，已默认处于 Permissive 模式）。
4. **自行安装宿主 Magisk**：
   由使用者按树莓派 AOSP 的启动分区布局与 [Magisk 官方安装文档](https://topjohnwu.github.io/Magisk/install.html) 自行安装宿主 Magisk。注意：树莓派的 `boot.img` 是包含 `Image` 与 `ramdisk.img` 的 FAT 分区，**切勿照搬普通手机直刷 `boot` 分区的命令**。
5. **安装 IrisBox 并导入 ROM**：
   安装 `IrisBox-0.1.6.apk`，打开应用依次执行 **“1 · 授权与检查” → “2 · 安装内置引擎” → “3 · 导入 ROM” → “4 · 管理实例”**。

## 5. 上游设备树参考与 `v0.1.2 / e13` 首发验收存档

- **上游 Manifest 与设备树参考**：宿主系统基于 [Raspberry Vanilla Android 13 Manifest](https://github.com/raspberry-vanilla/android_local_manifest/tree/android-13.0)（AOSP 基线 `android-13.0.0_r75`），固定仓库提交记录见 `reference/host-profile.json`，出厂 USB 启动配置保存在 `reference/host-boot/`（`cmdline.txt`、`config.txt`、`fstab.rpi4`）。
- **`v0.1.2 / e13`（2026-10-15）国际化与纯 AOSP 首发验收摘要**：
  - 公开纯 AOSP ROM（`IrisBox-rpi4-a13-aosp.irisrom`）通过系统文件选择器导入并校验入库；新建 1024 MiB 纯 AOSP+Root 临时实例在 `64,128 ms` 进入桌面（无任何 Google 包），普通 UID 联网、GPU、声音及 `640×360` H.264 软解播放全部通过，测试后删除该临时实例。
  - 保留实例 2（1536 MiB，Google+Root，`56,902 ms` 就绪）与实例 1（768 MiB，`61,813 ms` 就绪）双开回归、51 字节同名异文文件往返、各 10 次 JPEG 预览、Bearer 鉴权拒绝及音频故障注入（`11.36 秒` 恢复）全部通过；334 项中英文资源键、11 项归档安全测试及公开源码快照 44 项引擎载荷独立构建比对全部通过。

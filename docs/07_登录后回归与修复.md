## 2. 本轮定位并修复的 7 项核心问题

| 序号 | 问题领域 | 根因分析与工程修复方案 |
| :---: | :--- | :--- |
| **1** | **实例音频输出** | 原配置调用树莓派物理音频 HAL，但容器内无 ALSA 设备导致 `AudioTrack` 初始化失败。改为启用 ROM 自带的 `default` 虚拟 HAL，新增 `AudioBridge` 实现 **Guest `LOOP_BACK` 播放流采集 → `0700`/`0600` 受保护文件 Socket → 宿主 `AudioTrack` 混音输出**（不映射物理声卡，不含麦克风录音路径）。 |
| **2** | **音频进程退出与回收** | Java 入口初始化 `ActivityThread` 后存在非守护 Binder 线程，导致 `main()` 返回后进程仍驻留、监督脚本无限等待。改为完成 `AudioTrack`/`AudioPolicy` 清理后显式退出，并记录监督 Shell 的真实 `PID:start_tick`，确保停止实例时精确回收且释放 `audio.lock`。 |
| **3** | **视频解封装与软解** | 精简 ROM 禁用了 `mediaextractor`，且优先匹配了实例内不存在的 `V4L2` 硬件解码器。通过在私有物理路径 `rootfs/system/product/etc/init/zzz_irisbox_media.rc` 后加载恢复 `mediaextractor`，并在实例私有 `vendor` 编解码配置中移除 `V4L2` include，完整保留原厂软件 Codec。 |
| **4** | **单帧预览偶发崩溃** | 单帧 JPEG 抓图完成后的 C++ 静态析构与活跃 Binder 线程发生竞争，触发 `FORTIFY: pthread_mutex_lock called on a destroyed mutex`。修复 `buffer_producer.cpp` 在写出 JPEG 并解锁 buffer 后直接调用 `_exit(0)`（全屏流管线保持原协议不变）。 |
| **5** | **启动阶段 `Traceur` 崩溃** | 精简 ROM 缺少内核跟踪服务导致 `Traceur` 报错；早期尝试在包服务就绪后调用 `pm disable` 会在普通实例首次启动 `WindowManager` 尚未就绪时触发 `system_server` 空指针竞态。改为在 Guest `init` 启动前于私有挂载空间内用空 `tmpfs` 屏蔽 `rootfs/system/app/Traceur`，健康脚本仅只读观察 `WindowManager` 就绪。 |
| **6** | **构建与维护脚本可靠性** | Windows 换行符（`CRLF`）曾导致候选版监督脚本提前退出。打包器新增强制 `LF` 检查，维护升级提交前在设备端逐脚本执行 `sh -n` 校验；`tools/device.py` 针对调试 `su` 增加显式 `EXIT` 状态码标记，杜绝子命令失败仍返回 0 的误判。 |
| **7** | **引擎安装幂等与升级锁** | 引擎指纹改为按文件名排序的逐文件 SHA-256 清单（消除 `JSONObject` 无序序列化差异）；同版本重复安装仅执行幂等校验，跨版本维护期间存在 `engine-upgrade.pending` 时 App 拒绝拉起后台。 |

## 4. 宿主重启、启动顺序与内存保护验证

1. **真实树莓派重启**：正常停止两台实例后重启宿主，宿主 `boot_id` 由 `11e48d19-552f-4a85-bafc-5db16aa6d3a7` 变为 `e174fb52-9881-441b-8659-4c9bf8f796ea`。直接打开宿主 App 点击安装引擎完成同版本幂等校验（无需电脑重新推送文件）。
2. **内存准入保护验证**：
   - 若先启动普通实例 1（`49,975 ms` 就绪），再尝试启动 `1536 MiB` 的 Google 实例 2，此时准入检查要求 `1,835,008 KiB` 而宿主 `MemAvailable` 约为 `1,608,436 KiB`，系统**正确拒绝启动实例 2 并完整保护正在运行的实例 1**。
   - 正常停止实例 1 后，**先启动 `1536 MiB` 的实例 2（`57,972 ms` 就绪），再启动 `768 MiB` 的实例 1（`53,933 ms` 就绪）**，即可稳定达成双开（双开期间两实例 `cgroup OOM-kill` 均为 `0`，实例 2 峰值约 `1,398 MB`、`failcnt=0`，宿主剩余 `MemAvailable` 约 `842,036 KiB`）。

## Drive mirrors

Google Drive (international) and Quark Drive (China): awaiting owner uploads and share links. GitHub currently hosts the APK, guest Root/BusyBox sources and checksums. Large ROM, host image and complete kernel sources await owner mirrors. Mirror files must match SHA256SUMS.

Import `.irisrom` inside the App. The `.img.xz` is a whole-disk host image for a spare USB disk of 16 GB or larger. These formats are not interchangeable.
